# Client Preview physical-device checklist

Only mark PASS or FAIL after a real device check against the actual Vercel HTTPS URL. Browser automation on a desktop does not count as physical camera testing.

| Device | Check | Status |
|---|---|---|
| Android | Open HTTPS preview, mobile layout and navigation | NOT TESTED |
| Android | Customer order, voucher result and reload | NOT TESTED |
| Android | Camera permission, QR scan and manual fallback | NOT TESTED |
| Android | Voucher login and session persistence | NOT TESTED |
| Android | Signal Run touch controls on home/captive footer | NOT TESTED |
| iPhone | Open HTTPS preview, mobile layout and navigation | NOT TESTED |
| iPhone | Customer order, voucher result and reload | NOT TESTED |
| iPhone | Camera permission, QR scan and manual fallback | NOT TESTED |
| iPhone | Voucher login and session persistence | NOT TESTED |
| iPhone | Signal Run touch controls on home/captive footer | NOT TESTED |
| Laptop | Owner login, dashboard, reset and logout | NOT TESTED |
| Laptop | Staff assigned context and foreign-context denial | NOT TESTED |
| Laptop | Partner own tenant and masked customer data | NOT TESTED |
| Laptop | Customer journey and responsive layout | NOT TESTED |

Record device/browser/version, date, preview URL, observed result and tester next to each completed check. No production router or payment is involved.
